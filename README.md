# SitaRam Library — Next.js Single Page Website

A polished single-page Next.js + TypeScript website concept for SitaRam Library, Lucknow.

## Included sections

- Hero
- Facilities
- Membership Plans
- Gallery
- Reviews
- Location
- Contact

## Verified information used

- Business name: SitaRam Library
- City: Lucknow, Uttar Pradesh
- Google Maps link supplied for the project:
  https://maps.app.goo.gl/AmYkZHwvBsB9Rpum9

## Important

The supplied Google Maps page did not expose enough verified public text to safely publish:
- phone number
- opening hours
- membership pricing
- complete facilities list
- verified customer reviews
- official email

Those areas are intentionally written as editable/placeholder content so incorrect business information is not published.

The gallery currently uses a custom CSS illustration instead of pretending generic stock photos are photos of the real library. Replace the gallery/hero artwork with real SitaRam Library photographs before launch.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```
